about

Diet Tracker is a personal desktop utility for recording and reviewing diet information. It is maintained as a small personal software project and is not offered as a commercial service.

google account access

When the user chooses to connect Google, Diet Tracker uses only the permissions displayed on the Google consent screen and only for the user-requested application function. Access can be revoked at any time from the user's Google Account connections page.
