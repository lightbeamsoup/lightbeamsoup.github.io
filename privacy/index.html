privacy policy for apps hosted on joshcodes.ai

home lifetree energy garden

overview

joshcodes.ai hosts small browser-based tools. These tools are designed to keep user data in the browser or, when explicitly enabled by the user, in the user's own connected cloud account.

lifetree

Lifetree stores task data locally in the browser using local storage. If the user chooses to connect Google Drive, Lifetree requests Google authorization so it can save and load the task database from the user's Google Drive app data folder.

The app does not intentionally send task data to any server controlled by joshcodes.ai. Google account access is used only for the features the user explicitly invokes inside the app.

energy garden

Energy Garden stores entries locally in the browser. It does not use third-party account login.

data handling

Browser-stored data remains on the device and browser profile where it was created unless the user clears it. Google Drive-stored data remains in the user's Google account until the user removes it.

No guarantee is made that browser storage or cloud storage is suitable for highly sensitive data.

contact

For questions about this policy, use the contact or support email configured for the related Google OAuth application or the project links available on the site homepage.
