privacy policy for apps hosted on www.joshcodes.ai

home lifetree diet tracker r7-prime energy garden terms

overview

www.joshcodes.ai hosts small browser-based tools. These tools are designed to keep user data in the browser or, when explicitly enabled by the user, in the user's own connected cloud account.

lifetree

Lifetree stores task data locally in the browser using local storage. If the user chooses to connect Google Drive, Lifetree uses a backend service to request Google authorization and save or load the task database from the user's Google Drive app data folder.

For this sync feature, Google account identifiers, encrypted refresh tokens, and related sync metadata may be stored by the www.joshcodes.ai backend so the app can refresh access without requiring the user to sign in each time.

energy garden

Energy Garden stores entries locally in the browser. It does not use third-party account login.

diet tracker and r7-prime

Diet Tracker and R7-Prime are personal-use desktop applications. If a user chooses to connect a Google account, each application requests only the Google permissions shown on Google's consent screen and uses Google user data only to perform the feature the user requested.

Google user data is not sold, used for advertising, or shared with third parties except as needed to provide the requested application function or comply with law. OAuth credentials and application data are retained only as long as needed for the connected feature.

data handling

Browser-stored data remains on the device and browser profile where it was created unless the user clears it. Google Drive-stored data remains in the user's Google account until the user removes it.

No guarantee is made that browser storage or cloud storage is suitable for highly sensitive data.

A user can revoke an application's Google access at any time from the Google Account connections page. After revocation, the application can no longer obtain new Google access tokens. Locally stored application data can be removed by deleting the application's local data or uninstalling it.

contact

For questions about this policy, use the contact or support email configured for the related Google OAuth application or the project links available on the site homepage.
