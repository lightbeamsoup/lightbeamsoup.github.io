about

R7-Prime is a personal desktop automation and analysis utility. It is maintained as a small personal software project and is not offered as a commercial service.

google account access

When the user chooses to connect Google, R7-Prime uses only the permissions displayed on the Google consent screen and only for the user-requested application function. Access can be revoked at any time from the user's Google Account connections page.
